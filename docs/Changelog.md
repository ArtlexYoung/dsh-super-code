# 版本记录

中文 · [English](en/Changelog.md)

版本号格式为「主版本.效果版本.维护版本」。第二位变化表示编码效果或效率有提升；第三位表示修复、界面和兼容性更新。各版本的验证范围见[兼容性](Compatibility.md)。

## 0.3.11 · 2026-11-06

**卸载恢复与预设管理**

- 修复卸载插件后 Super Code 历史会话无法续聊的问题：已登记且归属匹配的会话改用官方标准预设继续，并显示一次切换提示；保留原会话与子任务历史、模型、目录和权限。
- 修复官方 minimal 在关闭删除保护、取消官方适用范围或停用、卸载插件后仍沿用旧规则的问题；切换保护等级不再重复叠加规则。旧摘要保留原文，并在后面补充明确的撤销说明。
- 修复预设恢复在异步读取、用户改选、插件重新启用及模块换代时使用旧状态的问题；旧实例不再迟到覆盖新记录或重复接管服务。
- 修复安装、重装失败回滚及语言同步可能覆盖外部变更、丢失归属记录的问题；保留用户修改及符号链接，拒绝无效记录，冲突时停止写入。

**任务侧栏、执行记录与用量**

- 修复任务侧栏只显示本轮要求的问题，保留最近 20 条历史要求及对应的已记录步骤；超过显示上限时明确提示。
- 修复执行详情缺少渲染的问题，复用宿主 Markdown 和代码组件，保留用户与工具输出原文，支持展开长内容。
- 补齐 PTC 子工具的调用、结果、失败及回合终止错误记录，崩溃恢复时正确显示中断状态；慢工具超出最近活动窗口后，成功的文件变更证据仍能保留。
- 修复执行记录分页与断线重连之间的重复读取、边界变化和阅读位置丢失；历史读取失败后可重试，关闭页面后不再回填。
- 修复 fork 继承历史被重复计入子 Agent 和执行树用量，以及模型标识含特殊分隔符时统计合并错误的问题；旧缓存会重建。
- 修复侧栏可全部收起的问题，任务、协作执行和记忆始终只展开一项，默认任务；切换保留阅读位置和草稿。

**设置、预算与记忆**

- 修复首页保存成功但随后刷新失败时显示旧设置的问题；修复自动保存尚未结束时可重复确认“恢复默认”、造成重复提交和版本冲突的问题。
- 修复自动压缩等待模型信息期间取消，之后仍裁剪工具记录或忽略取消的问题；保留原有压缩策略和预算默认值。
- 修复旧版记忆草稿在接口重连后继续使用旧接口的问题；保留草稿，主动重试使用当前接口，不自动重发进行中的写入。
- 修复删除最后一条记忆后，空主题仍占满 200 个主题额度的问题；额度按非空主题计算，同时保留并发修改检查，不增加内容版本记录。

**MCP 连接**

- 修复异步准备后仍使用已撤销目录授权或已关闭开关的问题；创建会话、选择模型和发送请求前重新核对当前授权与取消状态。
- 修复 `newConversation: false` 未指定 `taskId` 时仍创建对话的问题；现在要求先选择具体会话。
- 修复新建、续聊或取消的保存失败后，内存状态仍提前变更、错误占用额度或迟到取消的问题；准备期间保留上一轮跟踪，重启和重连不自动重发已保存请求。
- 修复审批等待取消后仍接受迟到批准的问题；单次审批重新核对取消、目录与开关状态，未决定的请求可交回 DSH 处理。
- 修复目录申请在路径被替换、校验期间过期或撤回后仍可批准的问题；已撤销的旧授权不会因复用申请而重新生效。
- 修复符号链接别名造成允许目录重复、移除后再次出现的问题；同一实际目录只保留一项，不可用目录仍可移除。
- 补齐 `dsh_read` 的 PTC 子调用公开记录；子工具活动计入进度观察，不再被误判为长时间没有进展。
- 修复初始化、凭据轮换、关闭和卸载竞态导致连接额度、端口或锁残留的问题；保存已成功时返回实际设置，清理失败明确提示并允许重试，不重新发送任务。

**命令与运行时**

- 修复部分 Shell 包装命令、`find`、`xargs` 及 PowerShell 启动参数的删除识别漏报和误报；仍由现有保护等级和宿主审批决定是否执行。
- 修复 Windows Shell 过滤、官方预算和 PTC 包装在卸载后残留或覆盖其他包装的问题；异步初始化落定后释放本插件资源，保留宿主与其他插件的状态。

各项修复按对应范围完成回归，版本契约、前端检查和完整宿主验收分别记录，不代表所有版本、所有平台均完成完整进程测试。本版未重新运行 100 题效果评测。

## 0.3.10 · 2026-11-03

**Windows 命令环境**

- 内置 GNU Bash、必要的 MSYS DLL、BusyBox 和 GNU grep，无需为了运行 Bash 命令额外安装 Git；Git、Node、Python 等开发工具仍需自行安装。
- 内置 Bash 默认开启；「同时应用到官方预设」默认关闭，开启后用于标准、PTC、创建模式，极简模式保留持久终端。设置自动保存，运行中的 Agent 保留原选择，子 Agent 继承。
- 仅 Windows 宿主可修改命令环境设置，其他平台灰显并显示「仅 Windows 生效」。修复就绪状态的对齐与长版本号换行，提示气泡随深浅主题变化。
- 修复旧目录预设在嵌套依赖布局下找不到宿主 Shell 模块、Windows PATH 别名与 BusyBox 固定参数覆盖，以及失败父子 Agent 被其他会话恢复误激活的问题。
- 严格删除保护识别 MSYS 的 `cmd.exe //c`、`//k` 删除命令。限权模式下 Bash 在执行前明确拒绝，仅由 DSH 审批放行该次调用，不自动修改权限或换 Shell 重放。

**文档与验证**

- README 追加官方与第三方插件的完整 Pro100 对比，按通过数排序，保留原开头成绩及各批次统计口径。
- 补齐最低版本至 rc.5 的 Windows Web 进程记录，以及官方 rc.5 Desktop、NEXT 的 Windows 专项验收；组件和静态前端检查单独记录。旧版原生 Windows 桌面未逐版验收，完整范围见[兼容性记录](Compatibility.md)。
- 固定命令集通过 97/100，剩余差异为 `.cmd` 引号和 MSYS 原生参数转换；不代表完整 Linux 环境。本版未重新运行 100 题效果评测。

## 0.3.9 · 2026-10-28

**界面**

- 美化首页、预设、预算、删除保护和连接设置；预算自动保存，输入无效或保存失败时保留草稿并提示，可重试或恢复默认。
- 侧栏任务更紧凑，工具调用按成功、失败和运行状态汇总，文件按项目相对路径显示；长列表继续使用虚拟滚动。
- 任务、协作执行、记忆最多展开一项，默认任务，点击当前标题可全部收起。保留圆圈执行树、运行动画、顶部提示和旧版记忆的新增、编辑、取消、保存及删除。
- 整理双语安装、使用及评测说明，更新 README 的设置、任务和执行树截图，并同步主干已有的历史评分复核记录，保留原始判分和校正依据。

**MCP**（服务仍默认关闭）

- 新增「允许 MCP 新增对话」（默认开启）；关闭时只能明确复用已有对话。新建对话归入已有工作区，未登记目录会创建同名工作区，标题以 `[MCP]` 开头。
- 可查询并选择模型和思考强度，省略时沿用会话当前或默认选择；选择保留在会话中。
- 新增 `dsh_status`、`dsh_models`、`dsh_read`、`dsh_approve`，支持容量诊断、公开对话分页读取及更明确的失败/恢复提示。修复历史子任务失败影响后续对话状态的问题。
- 新增「允许调用方审批」（默认关闭）；开启后仅批准或拒绝精确的单次操作，无法处理时回到 DSH。新增目录仍须用户在 DSH 同意。
- 修复 `run_code` 内子工具审批未转交 MCP 的问题：开启调用方审批后，按执行中的 Agent、调用 ID 和工具名匹配真实参数；批准仅对该次操作有效，拒绝或取消后清理请求，关闭开关时仍由 DSH 确认。
- 改善忙碌、重试和断线处理；明确保留 requestId、等待空位与 DELETE 释放客户端会话。新增 `super-code-mcp` 命令行入口。

只保留旧版记忆，不包含开发中的新版记忆、类型切换或迁移功能；普通对话的提示词和模型行为不变。本版未重新运行 100 题评测；历史评分复核不代表 0.3.9 的效果提升。验证范围见[兼容性记录](Compatibility.md)。

## 0.3.8 · 2026-10-26

**MCP 连接**（默认关闭）。[说明](UsageGuide.md#mcp-连接)

- 在本机 `127.0.0.1` 上提供 Streamable HTTP MCP 服务，使用凭证认证。
- 提供六个工具：`dsh_sessions`、`dsh_run`、`dsh_wait`、`dsh_send`、`dsh_cancel`、`dsh_request_directory`。外部客户端可委派 DSH 对话、查看进度、补充要求和取消任务。
- 沿用宿主的模型、预设和权限；不修改普通会话的提示词，不自动批准权限。
- 先通过 `dsh_sessions` 按目录查询最近对话和连接额度，由调用方明确选择复用或新建，不默认复用最新对话。
- 最大连接数与任务并发上限保持一致，默认均为 3，并保留用户已保存的值。
- 工作目录改为勾选列表，每次打开时刷新。外部申请新目录需在 DSH 弹窗中批准；撤销授权后无法通过复用绕过。
- 请求具备幂等性；重启后任务标记为中断，不自动重发；输出有长度上限；附带 Git 工作区观察结果。

**设置页**

- 新增首页：显示预设状态和版本、删除保护等级、MCP 开关以及在线/历史对话数。
- 客户端和关联会话详情移至「连接」页；删除保护单独成页；预设配置默认展开。
- 连接设置自动保存，凭证默认展开显示。

**修复**：读取工作区路径出错，导致有效目录显示「目录不可用」、无法启用连接。

## 0.3.6 · 2026-10-20

新版 Harness 收紧预算后效果下降。插件新增预算配置，默认恢复此前 Pro 评测中效果更好的旧预算，无需手动填写。[说明](UsageGuide.md#运行预算)

- 默认值：按完整上下文窗口计算，用量达到 80% 时触发压缩，保留最近 16% 的原文，摘要上限 8,192 token，压缩追加和溢出重试各 1 次；支持 PTC 时限配置的新版宿主，默认时限和上限均为 600 秒。
- 用户自定义值优先；运行中的 Agent 保留原配置；旧宿主不支持的时限项会禁用；所有值均不超过宿主上限。
- 官方预设仍需手动开启后才应用。
- 设置页分为「预设状态」和「上下文配置」，支持保存、恢复默认和并发修改冲突检查。
- 修复：语言偏好尚未保存时页面提前重载，导致语言回退。
- 未新增或改写历史评测成绩。
