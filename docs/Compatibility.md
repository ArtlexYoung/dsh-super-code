## 验证方法

- 每个宿主使用独立 profile，宿主依赖固定版本并经过审计，不影响日常使用的应用和配置。
- 模型响应由本地确定性程序提供，经过真实的宿主 Agent 和工具链。**未调用外部模型**，因此不属于效果评测。
- Web 端使用 Chromium；原生端在 macOS arm64 上运行，rc.4 官方 x64 包另通过 Rosetta 验证，未使用 Intel 实机。
- 每次发布均同时运行全量单元测试、类型检查、构建和客户端语法检查。

## 未覆盖的范围

- Windows、Linux 原生客户端、Intel 实机、Safari 专属行为
- 真实模型服务、完整的升级与自定义配置回归、所有工具组合
- 窄窗口：宽度为 440px 时，宿主侧边栏仅为插件保留 156px，视为不可用（未安装插件时设置页存在同样问题）
- 原生目录选择器的确认与取消（系统辅助功能接口超时）
- MCP 客户端能否根据连接 Prompt 自动完成配置
- 各版本的冷下载安装（测试复用了缓存的宿主依赖）

依赖声明中的版本范围不等同于验证结论，未列出的版本需单独验证。

## 安装问题排查

预发布版本的 `^` 范围可能解析到其他 alpha/rc 版本，导致宿主组件版本混用。例如：

- 安装 `0.1.6-alpha.1` 时混入 alpha.2，插件加载前即报 `watchUserPatches` 导出缺失。
- 安装 `0.1.7-alpha.1` 时混入 rc.1。

测试环境通过精确的 overrides 解决该问题，但无法修复上游的依赖声明。遇到类似错误时，请先核对实际安装的宿主组件版本。

按照 npm 规则，`>=0.1.5-alpha.1 <0.3.0` 这类写法会排除 `0.1.6-alpha.1`、`0.2.0-rc.2` 等预发布版本，因此 peer 依赖只能按系列分别列出。

`zod`、`js-yaml`、`@modelcontextprotocol/sdk` 为运行依赖，不打包进插件。发布包仅包含插件、公开文档和截图。

- **初次界面验收**：整合候选标记为 0.3.8，首次 0.3.9 发布的运行代码与该候选逐字节一致；284 项测试通过。使用官方 React、主题和控件配合本地模拟服务，30 个前端目标通过 390 组交互（Web `0.1.5-alpha.1` ~ `0.2.1-rc.4`、6 个官方桌面前端、2 个 NEXT 前端），覆盖中英文、深浅主题、自动保存与失败、预设状态、自定义下拉、窄布局、运行圆圈和长列表。**前端检查不等于真实宿主验收。**
- **真实界面与持久化**：官方 Desktop `0.2.1-rc.3`、NEXT `2.0.19-next`，以及 10 月 28 日追加的完整 Web `0.2.1-rc.4` 和官方 Desktop `0.2.1-rc.4` x64/Rosetta 宿主，通过设置、真实 MCP SDK 连接、工作区刷新与授权撤销、旧版记忆增删改与取消、任务投影与虚拟滚动、冷重启恢复；无页面脚本错误。rc.4 使用固定并审计的 274 个官方组件。
- **本次修复回归**：修复 `run_code` 子工具审批无法转交调用方的问题；全量 289 项测试、类型检查、构建与客户端语法检查通过。20 个原有 Web 引擎版本（最低 `0.1.5-alpha.1` 至 `0.2.1-rc.2`）和 `0.2.1-rc.4` 各通过 28 项审批/删除保护回归。
- **真实审批链路**：修复包在 Web `0.1.5-alpha.1`、Web `0.2.1-rc.4`、官方 Desktop `0.2.1-rc.3` / `0.2.1-rc.4`（x64/Rosetta）、NEXT `2.0.19-next` 串行通过 `run_code → bash` 的准确参数转交、批准、拒绝、取消、跨任务隔离、过期决策拒绝、关闭开关留给 DSH 和容量恢复；批准仅删除任务专用临时文件，拒绝与取消均保留文件。
- **rc.4 MCP 全流程**：官方 Web 和官方桌面 x64/Rosetta 均另复验预设改名重装与备份、旧预算默认值与输入/冲突校验、模型与思考强度实际传入、显式复用与后续消息、公开历史分页、目录同意/拒绝、3 连接和 3 任务上限、取消回收、子 Agent 历史及断线重连。
- 所有真实宿主使用本地确定性模型响应，**未调用外部模型**。侧栏最多一项展开，默认任务，也可全部收起；只包含旧版记忆，不含新版记忆、类型切换或迁移。
- rc.4 桌面使用官方 mac-x64 nightly ZIP（SHA-512 与官方清单一致，原应用签名校验通过），在 macOS arm64/Rosetta 下运行；不是改版号的 rc.3 或源码替代包。mac-arm64 频道仍为 rc.3，rc.4 arm64 ZIP 返回 404；**原生 arm64 rc.4 包尚未验收**。未重新验证原生目录选择器。
