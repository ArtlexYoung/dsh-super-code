# 评测说明

公开结果比较同一批 SWE-bench Pro hard-100 任务上的 DSH `minimal` 与 `super-code`，两组使用相同模型与 `high` 推理等级，经原生 DSH Web RPC 执行并使用官方评分器评分。

- [结果概览](swebench-pro-pro-hard-100.md)
- [题目索引与每题明细](../../eval/results/swebench-pro-final-100/)

输入 token 包含缓存读取；每题用量汇总已记录的模型请求，再对任务取平均。未返回用量的请求不估算为零，因此用量统计不等于完整账单。

公开 JSON 是经过脱敏的结果副本。模型必要时使用统一展示名称，省略开发路由、本地环境配置、机器路径和原始工具诊断；评分、计数、用量与耗时保持原值。它们可用于检查结果与统计，不是可直接重放的请求配置。原始运行证据及内部运行脚本不发布。
