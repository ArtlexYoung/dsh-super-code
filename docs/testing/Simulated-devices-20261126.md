## 验收中修复的问题

全局记忆要求条目不携带项目版本字段 `sourceVersion`。旧版遇到该字段时只提示“只接受有来源的用户偏好”，工具帮助也未指出要省略这个字段；即使请求已有真实用户引文，模型仍反复尝试修改措辞，无法得知真正原因。

本轮将错误提示改为明确要求去掉 `sourceVersion`，帮助中也加入同样说明。原来的来源、确认和版本校验保持不变。新增回归先在旧实现上失败，再验证拒绝请求不写入数据、去掉该字段后正常保存。20 项相关源码回归、类型检查、编译及 2 项分发检查通过。新候选在中转及 AA 宿主的 6165 个文件逐一匹配。

真实模型复验时，模型先沿用旧参数，收到新错误后只纠正一次便保存成功，并在同一轮继续回读。之后冷重启仍能读取全局偏好、项目记忆和任务。该结果说明本次错误能够被纠正，不是对所有模型成功率或耗时的承诺。

首次中转任务将测试数值作为全局记忆，随后又在偏好条目里附带项目版本，分别导致拒绝和反复尝试；两个回合均从手机取消。第一次回合已经保存的文件、任务和项目记忆在取消及冷恢复后仍可读，后续没有重复写入。旧失败不计为通过。

## 连接限制和未验证范围

- dsh-Go 在宿主冷重启后曾持续显示断开，点击“重新同步”未恢复；重开 App 后恢复原会话和未发送草稿，并完成冷续聊。切换到后台再返回也出现过连接中状态，不能称自动重连稳定。
- SSH 首次通过认证与隧道测试后，会话列表仍长时间连接中；后来创建可见历史、从中转切回 SSH 后可用。未单独确定恢复原因，也未修改第三方 App。
- AA 不显示没有用户消息的空会话，这是原装桥接的可见性规则；添加准备消息后会话正常同步。
- 手机上的审批批准/拒绝、带延迟消息的同 ID 双宿主切换、精简历史内容、AA 全局记忆专项、全部原生插件面板尚未完成。取消已有真实手机操作证据，但不等于所有审批与恢复组合通过。
- iOS 没有已安装的模拟器运行时，官方 Go IPA 也不是 iOS 模拟器构建；本轮未验证。Android 实体手机、Intel Mac 实机、macOS FUSE、Windows x64 原生应用及 SFTP、物理拔网线仍按原报告保留缺项。Rosetta、虚拟服务器停止和 Android 模拟器分别只覆盖对应模拟条件。

中转前置环境曾把 HTTP 地址写成 Docker 主机别名，触发官方 HTTPS/私网校验，导致控制接口未注册；改用允许的私网 IP 后正常上线，未修改第三方插件。AA 初始只启动 API 后端，缺少网页登录前端；补齐官方前端后登录成功。Rosetta 前两次缺 x64 原生依赖，补齐隔离环境后第三次通过。这些准备失败与产品修复分别记录。
