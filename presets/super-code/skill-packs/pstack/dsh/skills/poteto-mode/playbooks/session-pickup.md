### Session pickup

1. Identify the exact prior session/handoff or branch. Use the public DSH history tools when present, otherwise the supplied export and project-local plans/logs as described in DSH.md. Read the overview and most recent events before expanding the relevant decision points. Do not guess private journal paths.
2. Reconstruct branch/worktree state, completed artifacts, decisions, tests and open items. Preserve the difference between recorded observations and an agent's summary.
3. Compare done versus pending against the user's goal and later corrections. Recheck only mutable claims or missing evidence; don't repeat completed work without a reason.
4. Choose the inherited task's outcome: continue execution, deliver a finished recommendation, ratify or override a prior conclusion, or investigate a failed run. Route pending work to the matching playbook; that playbook owns execution after this pickup. The root schedules each dependent phase; a history-reading child returns a sourced capsule.
5. Verify inherited claims on the real artifact before relying on them. If essential history is unavailable, identify the smallest export or decision needed and continue independent work.

Reply with the previous stopping point, inherited versus rechecked work, the resumed step and its outcome.
